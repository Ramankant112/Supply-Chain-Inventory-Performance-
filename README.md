# 📦 Supply Chain & Inventory Analysis

## 📌 Project Overview

This project focuses on analyzing **supply chain and inventory data** to understand stock levels, supplier performance, delivery delays, and product profitability.

The project uses **15,000 records** and aims to find useful business insights that can help improve inventory planning and decision-making.

---

## 🎯 Project Objective

The main objectives of this project are:

* Analyze inventory and stock levels
* Track supplier performance
* Identify delivery delays
* Understand product profitability
* Find overstocked and understocked products
* Identify fast-moving and slow-moving products
* Create an interactive dashboard for business decisions

---

## 📂 Dataset

The dataset contains **15,000 records** with information about products, suppliers, inventory, sales, pricing, warehouses, and shipping time.

### Main Columns

* Product_ID
* Product_Name
* Category
* Supplier_Name
* Order_Date
* Delivery_Date
* Stock_Quantity
* Reorder_Level
* Units_Sold
* Purchase_Cost
* Selling_Price
* Warehouse_Location
* Shipping_Time_Days

---

## 🧹 Data Cleaning

Before analysis, the data was checked and cleaned by:

* Removing duplicate records
* Handling missing values
* Formatting date columns
* Checking numeric columns
* Checking negative or incorrect stock values

## ❓ Business Questions

This project answers the following business questions:

1. Which products are frequently out of stock?
2. Which suppliers have the highest delivery delays?
3. Which products generate the highest profit?
4. How can inventory be optimized?
5. What is the impact of delivery delays on sales?

---

## 💡 Key Insights

* **Tablet** was frequently understocked and needs regular monitoring.
* **Supplier E** had the highest delivery delays.
* **Camera** generated the highest profit.
* Inventory can be improved by maintaining proper reorder levels.
* Delivery performance should be monitored to support smooth supply chain operations.

This project helped identify important inventory, supplier, delivery, and profitability issues.
